# Kestrel 1.7.0 — Nested search and lasting permissions

Find files and folders using paths such as `dev/docs`, `kestrel/docs/demo`, or a partial final name like `dev/do`. Home (`~/`) and absolute paths work too; add a trailing `/` to show only folders. Searches use Spotlight and your existing macOS permissions.

Official builds now keep a consistent signing identity across updates, helping macOS retain your privacy permissions.

## Existing users: one-time Full Disk Access approval

**When upgrading from 1.6.1 or earlier, users who enabled Full Disk Access may need to approve Kestrel once more.** The app is moving from its old signature to a persistent identity. Your settings, snippets, and clipboard history stay in place.

If protected-folder search stops working after updating:

1. Open **System Settings → Privacy & Security → Full Disk Access**.
2. Remove the old **Kestrel** entry from this permission list, then use **+** to add **/Applications/Kestrel.app** and enable it. Authenticate if asked. This removes only the permission entry—not the app or your data.
3. Choose **Quit & Reopen**, then check **Kestrel Settings → Search → Check access**.

Future official updates using this identity are intended to retain the approval. This was confirmed through a real Sparkle update on macOS 27.0.1; other Macs and older supported macOS versions still need verification. Locally built ad-hoc apps have a different identity and may need approval again.

Full Disk Access remains optional. Apps, Google search, the calculator, and snippets work without it. You do not need to install a certificate or create any signing keys.

## Update

From **1.6.0 or later**, choose **Check for Updates…** in the wing menu or General settings. Automatic checks notify you; you choose when to install. **1.5.0 and earlier** need one manual replacement using the app ZIP.

## Compatibility

Apple silicon · macOS 14+ · build 13 · preview. Self-signed and **not Apple-notarized**; the initial macOS installation warning remains. Follow the [first-launch guide](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#first-launch) for a trusted download. Separate-Mac and macOS 14 acceptance remain unverified.
