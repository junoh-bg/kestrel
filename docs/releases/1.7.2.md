# Kestrel 1.7.2 — More reliable file search

Matching results now appear in this order:

1. Applications
2. Folders
3. Files
4. Kestrel Settings and Google search

A matching application stays above folders and files when Spotlight results arrive. Within each type, match quality and learned usage still decide the order. File-only searches show folders before files. Deliberate keyboard selections remain selected when additional results arrive.

## Find hidden dotfiles

Queries such as `.env`, `.env.local`, and `.gitignore` now supplement Spotlight with a background filename scan. This finds dotfiles that Spotlight may omit. The scan covers Desktop, Documents, Downloads, and folders selected in Search settings; an absolute dotfile path searches its parent directly. No file contents are opened or indexed.

Dotfile queries show up to 120 scrollable local matches instead of twelve. Large or unreadable folder trees can produce partial results; Kestrel shows a notice. Dependency, VCS, build, cache, and app-package contents are skipped, and directory symlinks are not followed. Ordinary file queries still rely on Spotlight.

## Update

Once published, choose **Check for Updates…** in the wing menu or General settings. Installation asks first. Settings, snippets, and clipboard history remain in place, and official builds retain the persistent signing identity.

Users upgrading directly from 1.6.1 or earlier may need the [one-time Full Disk Access refresh](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#one-time-permission-refresh-for-170). Self-signing does not provide Apple notarization: macOS may still require **Open Anyway** under Privacy & Security. See the [setup guide](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#first-launch).
