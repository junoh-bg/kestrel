# Kestrel 1.6.1 — Settings readability fix

Fixed hard-to-read checkbox labels in **Settings → General** and **Settings → Clipboard**, including “Check automatically.” Labels now use the selected theme's text color consistently.

All five Settings sections were reviewed across all five themes. Added pixel-level checks for checked, unchecked, and disabled checkbox labels under both legacy and current macOS rendering paths.

## Update

From Kestrel 1.6.0, choose **Check for Updates…** in the wing menu or General settings, then approve installation. Version 1.5.0 and earlier need one manual app replacement. Saved settings and snippets remain in place.

## Compatibility

Apple silicon, macOS 14+, build 12. This preview remains ad-hoc signed and **not Apple-notarized**. Follow the [first-launch guide](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#first-launch) if macOS blocks a trusted download. Separate-Mac and macOS 14 acceptance remain unverified.
