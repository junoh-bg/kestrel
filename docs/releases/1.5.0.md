# Kestrel 1.5.0

**Design and actions preview · 2026-10-14 · Build 10**

A more compact search experience, refreshed themes, and useful actions for the result you select.

## What's new

- **Compact launcher.** Starts small and expands to fit results, with up to seven visible rows and a stable top edge.
- **Five refreshed themes.** Nightflight, Moss, Dusk, Linen, and Frost share native background blur and a consistent layout. Reduce Transparency uses a solid background.
- **Actions with Command–K.** Open the selected result, show local items in Finder, or copy their path. Calculations and snippets offer a copy action.
- **Clearer Settings.** Readable theme transitions, padded buttons, aligned controls, and a backed title bar.
- **Keyboard fixes.** Command–K and Command–W work with Korean input enabled; selected folder icons remain visible in light themes.
- **Updated English demo.** See app, folder, and file search, Google search, calculations, snippets, and theme customization in the new interface.

**Option–Space still opens Kestrel. Escape and Command–W still dismiss it.** Existing theme choices keep their palette family. Clipboard history stays off on a fresh install.

## Install or update

Requires an **Apple silicon Mac with macOS 14+**. Download **Kestrel-1.5.0-macos-arm64.zip**, unzip it, and move **Kestrel.app** into Applications. For an update, quit the old app before replacing it, then reopen it. Saved preferences, snippets, and history retain their existing storage location. Folder permissions may need approval again after an update.

This preview is **ad-hoc signed, not Developer ID signed or Apple-notarized**. macOS may block first launch. For a trusted download, follow the [first-launch guide](https://github.com/junoh-bg/kestrel/blob/v1.5.0/docs/getting-started.md#first-launch), including **System Settings → Privacy & Security → Open Anyway**. Managed Macs may not permit this approval.

## Verification and limitations

72 Swift tests and 3 packaging tests passed locally on macOS 27.0.1. Release packaging, signature consistency, and isolated startup checks were verified. Native views were checked across all five themes. A separate-Mac downloaded installation and macOS 14 acceptance remain unverified.

File results depend on Spotlight and folder permissions. Clipboard history stores unencrypted text locally when enabled. Snippets copy text for manual pasting. Updates are manual. Intel Macs, workflows, and automatic text expansion are not supported in this preview.
