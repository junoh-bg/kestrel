# Kestrel 1.4.2

**First open-source preview · 2026-10-14**

Kestrel: everyday Mac tools, one shortcut away.

## Included

- Open apps and find local files and folders with Option–Space.
- Search Google, calculate, recall clipboard text, and copy saved snippets.
- Choose from five themes with readable navigation and compact controls.
- Install a ready-to-use app or build from source.
- MIT-licensed source, a versioned download, setup guide, and checksum.
- A copyable setup prompt and installation guide for Claude Code, Codex, and other local coding agents.

## Install

Requires an Apple silicon Mac with macOS 14 or later. Download **Kestrel-1.4.2-macos-arm64.zip**, unzip, and drag **Kestrel.app** into Applications. Open it and press **Option–Space**. Quit another launcher if it uses the same shortcut.

This preview is **ad-hoc signed, not Developer ID signed or Apple-notarized**. macOS may block first launch. For a trusted download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. Read [setup help](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#first-launch); managed Macs may not permit this. No App Store or paid Apple Developer account is needed to download or build Kestrel.

Tested locally on macOS 27.0.1. A separate-Mac downloaded installation and macOS 14 acceptance have not yet been verified.

## Before you start

Clipboard history is off by default and stores unencrypted text locally when enabled. File results depend on Spotlight and folder permissions. Snippets copy text for manual pasting. Updates are manual; Intel Macs, workflows, and automatic text expansion are not supported in this preview.

Existing users: quit Kestrel before replacing the app. Preferences and snippets retain their existing storage location. Folder permissions may need approval again after replacing an ad-hoc-signed build.
