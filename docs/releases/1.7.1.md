# Kestrel 1.7.1 — Newly installed apps appear automatically

Kestrel now refreshes its app list in the background whenever you open the launcher, and every five seconds while it stays visible. Apps installed after Kestrel starts—including apps inside Applications subfolders—appear without restarting or using Refresh applications. Renamed and removed apps are updated too.

The previous list stays available while refreshing, so typing remains responsive. Search results update when a changed list is ready. App discovery reads the Applications folders directly and does not wait for Spotlight indexing.

## Update

Choose **Check for Updates…** in the wing menu or General settings once this version is published. Automatic checks notify you; installation asks first. Settings, snippets, and clipboard history remain in place.

Official builds retain the signing identity introduced in 1.7.0. Users upgrading directly from 1.6.1 or earlier may need the [one-time Full Disk Access refresh](https://github.com/junoh-bg/kestrel/blob/main/docs/getting-started.md#one-time-permission-refresh-for-170). No new permission approval is expected when upgrading from the signed 1.7.0 release.

Apple silicon · macOS 14+ · build 14 · preview. This app is self-signed, not Apple-notarized; the initial installation warning remains.
