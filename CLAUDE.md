# Kestrel

Native macOS 14+ launcher using Swift and AppKit. No third-party runtime dependencies.

Keep the legacy `com.localpilot.launcher` bundle identifier, `Application Support/LocalPilot` data directory, and `LOCALPILOT_DATA_DIR` developer override stable for upgrades. Never package user clipboard history, snippets, credentials, or private research.

`version.json` owns the release version and build number. Update the changelog and matching release notes with every distributed version. Follow `docs/releasing.md`; do not label ad-hoc builds as notarized.

Run `swift test --no-parallel`, `python3 -B -m unittest discover -s Tests/Packaging -v`, `swift build -c release`, and `scripts/package.sh` before delivery. Format Swift with `xcrun swift-format format --in-place --recursive Sources Tests Package.swift scripts/MakeIcon.swift` and lint with `lint --strict` instead of `format --in-place`.

Clipboard capture starts off. Filter concealed, transient, and autogenerated pasteboard content. Do not execute shell commands for user search input. Snippets copy text; automatic expansion is not implemented.

Treat AppKit control internals as opaque when updating themes. Verify live light-to-light and light-to-dark transitions. Preserve user settings and keep prior local app packages under ignored `dist/archive/` when replacing them.

All palettes share the same layout, interaction model, and material treatment. Preserve persisted theme IDs when changing display names. Respect Reduce Transparency with an opaque surface. Custom result selection must retain legible template icons in light themes.

Launcher Command shortcuts must work with non-Latin input methods as well as Latin layouts. Contextual actions must capture their target so asynchronous search cannot redirect an open action menu.
